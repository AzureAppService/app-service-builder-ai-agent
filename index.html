Before you connect a model

This page is a static showcase. It does not collect credentials, send prompts or verify configuration. Real API requests require a separately configured provider and can incur model-service charges. Never include secrets or sensitive data in prompts. App Service Builder hosts the web application, not the model. This development sample is not a production identity or abuse-protection design.
