Configure your own app before connecting a model

server.mjs reads APP_API_TOKEN and MODEL_SERVICE. OpenAI uses OPENAI_API_KEY and OPENAI_MODEL; Azure OpenAI uses AZURE_OPENAI_ENDPOINT, AZURE_OPENAI_API_KEY and AZURE_OPENAI_DEPLOYMENT. Optional PUBLIC_ORIGIN must be an exact HTTPS origin. Configure these in your own app, then restart locally or save and deploy a new version. This page cannot discover your fork or change deployment settings.

This public guide only checks server liveness. It does not collect credentials, send prompts or verify model configuration. Real API requests require a separately configured provider and can incur model-service charges. Never include secrets or sensitive data in prompts. App Service Builder hosts the web application, not the model. This development sample is not a production identity or abuse-protection design.
